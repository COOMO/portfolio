benchpress

Windows desktop app for a lab bench. Controls instruments over GPIB and Ethernet. Test sequences are blocks, not code. 實驗室用的 Windows 桌面程式。透過 GPIB 與 Ethernet 控制儀器。測試流程是積木，不是程式。

Problem問題

  • An R&D lab ran its bench on a LabVIEW station. It worked.一間研發實驗室的工作站跑 LabVIEW。能用。
  • Each new instrument meant days of wiring code. Each new test was a new VI.每加一台儀器要寫好幾天接線程式。每個新測項是一個新 VI。
  • Nothing was in version control. No tests.沒有東西在版本控制裡。沒有測試。
  • The brief, in the lab's words: swap instruments freely, compose tests like blocks, run several buses at once.實驗室的要求：儀器隨時換、測項像積木一樣組、多條介面同時跑。

Solution解法

  • An instrument is one row in instruments.toml plus one template file. No Rust changes.一台儀器是 instruments.toml 一列加一份模板檔。不動 Rust。
  • A test is a sequence of blocks: Write, Query, Wait, For, If, Parallel, Shell, Set Variable, Print.一個測項是積木序列：Write、Query、Wait、For、If、Parallel、Shell、Set Variable、Print。
  • Everything is plain text in one folder. Diffs in git. An LLM can write a template from a manual.全部是純文字，放在一個資料夾。git 可 diff。LLM 可以照手冊寫模板。

Key screens主要畫面

Test Panel

  • Add an instrument by VISA address. Probe with *IDN?.用 VISA 位址加入儀器。*IDN? 探測。
  • Send raw SCPI. Save it as an Action with named parameters.直接送 SCPI。存成帶參數的 Action。
  • The panel is generated from the template file. No per-instrument UI code.面板由模板檔產生。沒有針對單一儀器的 UI 程式碼。

Sequence Editor

  • Three panes: actions, steps, inspector with live command preview. Event log below.三欄：動作、步驟、檢視器（即時指令預覽）。下方事件 log。
  • Breakpoints, pause, step over, step into.中斷點、暫停、逐步執行。
  • Variables with ${name} substitution and a small expression engine.變數可用 ${name} 代入，附小型運算式引擎。
  • Parallel: one lane per instrument. Same GPIB board shares a lane.平行：每台儀器一條車道。同一張 GPIB 卡共用一條。

Manage

  • Three tables: instruments, actions, sequences. One TOML file each.三張表：儀器、Action、序列。各一份 TOML。
  • The GUI watches the folder. Edits from an editor, git or the MCP server show within a second.GUI 監看資料夾。編輯器、git、MCP server 的改動一秒內出現。
  • Per-instrument stop command lives here. Chroma LOAD OFF, Keysight INP:STAT OFF, ITECH INPut:STATe OFF.各儀器的停機指令在這裡。Chroma LOAD OFF、Keysight INP:STAT OFF、ITECH INPut:STATe OFF。

Features功能

For the engineer給工程師

  • Pre-flight opens every instrument a sequence needs, in parallel.執行前平行開啟序列用到的每台儀器。
  • Per-step failure policy: Halt, Continue, Retry N.每步失敗策略：Halt、Continue、Retry N。
  • Aggregate FOR: mean, std, min, max across iterations, CSV out.FOR 彙總：跨迭代的平均、標準差、最小、最大，可出 CSV。
  • Shell steps in Bash or Python with a highlighted editor.Shell 步驟支援 Bash、Python，附語法高亮。
  • Every run: execution.jsonl, screenshots, report.html. Header has operator, DUT serial, sequence hash, calibration dates.每次執行：execution.jsonl、截圖、report.html。表頭含操作者、DUT 序號、序列雜湊、校正到期日。

For scripts and LLMs給腳本與 LLM

  • benchpress.exe run <sequence> --mock | --hardware. Same compile, same report, exit codes.benchpress.exe run <sequence> --mock | --hardware。同一套編譯與報告，有 exit code。
  • benchpress.exe probe <addr>: one query, timing, hex tail, a hint per VISA error.benchpress.exe probe <addr>：一條查詢、耗時、hex 尾端、每種 VISA 錯誤一句提示。
  • MCP server for Claude Desktop, Claude Code, Cursor. Lists instruments, validates and saves TOML, reads past runs. File only, never touches VISA.MCP server 給 Claude Desktop、Claude Code、Cursor。列儀器、驗證並存 TOML、讀過去的執行。只碰檔案，不碰 VISA。
  • A sequence MCP accepts is one Run accepts: same compiler.MCP 收下的序列，Run 一定收：同一個編譯器。

For the lab manager給實驗室管理者

  • Roles: admin, author, operator, viewer. Mapped from Windows accounts.角色：admin、author、operator、viewer。對應 Windows 帳號。
  • Audit trail: app start, sequence saved, run started, MCP writes.稽核紀錄：啟動、存序列、開始執行、MCP 寫入。
  • One-click diagnostics bundle: config, logs, newest run.一鍵診斷包：設定、log、最新執行。
  • Offline licensing, ed25519 signed, node-locked. Base app free; a license unlocks premium flags.離線授權，ed25519 簽章、綁機器。基礎功能免費，授權解鎖付費功能。
  • Installs to one folder on the desktop. Nothing in %LOCALAPPDATA%.安裝到桌面一個資料夾。不碰 %LOCALAPPDATA%。

Safety and verification安全與驗證

Outputs never auto-enable輸出絕不自動開啟

  • Templates mark dangerous commands with danger = true. GUI asks "Run anyway". CLI needs --confirm-danger.模板用 danger = true 標記危險指令。GUI 要按「Run anyway」。CLI 要加 --confirm-danger。
  • Stop, fatal error, window close, panic: each sends every instrument's on_stop_scpi.Stop、嚴重錯誤、關閉視窗、panic：都送出每台儀器的 on_stop_scpi。

Green tests are not a working feature測試綠不等於功能可用

  • CI runs about 350 tests on MockVisa with no instrument attached.CI 用 MockVisa 跑約 350 個測試，不接儀器。
  • Hardware tests are #[ignore] and run only with BENCHPRESS_HW=1.實機測試標 #[ignore]，只在 BENCHPRESS_HW=1 時跑。
  • Acceptance has two layers: open and *IDN?, then every template command on the real unit. Logged per instrument with firmware and commit.驗收兩層：先開啟與 *IDN?，再把每條模板指令送到實機。每台記韌體與 commit。
  • Verified so far: R&S RTB24, firmware 03.000, 21 steps, three screenshots, report. 2026-09-06.目前已驗：R&S RTB24，韌體 03.000，21 步、三張截圖、報告。2026-09-06。

Every push is watched to the end每次 push 都盯到 CI 結束

  • Gates: cargo fmt, clippy -D warnings, cargo test, then gh run watch.關卡：cargo fmt、clippy -D warnings、cargo test，再 gh run watch。
  • Reason: a tokio flush-before-drop bug that only ever reproduced on the runner.原因：一個只在 CI runner 上重現的 tokio flush-before-drop bug。
